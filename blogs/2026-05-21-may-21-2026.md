Google Drive API Feature Developer Preview : The copy_file tool is now available for the Google Drive MCP server. AI agents or client applications can use this tool to copy an existing file in Google Drive, with options to specify a new title and redirect it to a specific parent directory. To learn more about configuring and using the Drive MCP server, see the following pages: Set up the Drive MCP server Drive MCP tool reference
