Chat API Announcement OAuth 2.0 clients calling the Google Chat Model Context Protocol (MCP) server are required to have Use this client for an AI-powered agent selected in Google Auth Platform > Clients . Starting November 11, 2026, Google Workspace MCP servers will reject requests from any app or integration whose OAuth client is not marked as agentic by selecting Use this client for an AI-powered agent . OAuth clients that are not marked as agentic by November 12, 2026 will remain non-agentic and can't call Google Workspace MCP servers.
