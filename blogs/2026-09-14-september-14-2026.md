Google Apps Script Feature Generally Available: Apps Script now supports data regions in Google Workspace, adhering to organizational data location policies configured in the Google Admin console: Data at rest: Script project files, code definitions, manifest configurations, trigger metadata, and key-value storage (such as Property Service and Cache Service) are stored within the designated geographic region. Data processing: Script executions, container-bound automations, and associated runtime operations are processed within the selected region. This feature is available for Google Workspace
