Google Docs API Feature Developer Preview : The Google Docs Model Context Protocol (MCP) server now supports reading and managing document comments: Include comments when reading a document by setting the optional commentsIncluded field on the read_doc tool. Create, reply to, resolve or reopen, update, and delete comments and replies using the update_doc tool with the insertComment , addCommentReply , updateCommentPost , deleteComment , and deleteCommentReply operations. To learn more, see Configure the Docs MCP server and the Docs MCP tool reference .
