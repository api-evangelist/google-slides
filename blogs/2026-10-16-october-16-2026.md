Chat API Feature Generally Available: You can now configure an app-level default Markup syntax —to use standard Markdown syntax or the original Google Chat syntax—on the Google Chat API Configuration page in the Google Cloud console, which starts to roll out today, with an expected completion in the next few days. You can also override the app-level default on individual API requests by specifying the markupSyntax field in the Message resource when creating, updating, or reading Google Chat messages. For more information, see Configure the Google Chat API and Format messages .
