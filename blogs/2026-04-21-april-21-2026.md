Google Drive API Feature Generally Available : The Google Drive API now lets you start and manage approvals on Drive files through the approvals resource. The following API methods have been added: approvals.start approvals.approve approvals.decline approvals.reassign approvals.cancel approvals.comment You can still retrieve and list the status of your approvals using either the approvals.get or the approvals.list method. For details, see Manage approvals .
