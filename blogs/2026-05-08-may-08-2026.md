Chat API Feature Generally Available : Chat apps using app authentication can now send a forced notification when sending a message or send a message silently by setting the createMessageNotificationOptions field in the CreateMessage request. You can use these options to notify users: Forced notifications : Overrides recipient notification settings and Do Not Disturb (DND) status to ensure the message is delivered as a push notification. Silent messages : Suppresses push notifications and prevents the message from bolding or bumping the space in the recipient's list.
