Google Sheets API Feature Developer Preview : You can now programmatically create and manage comments in Google Sheets with the Google Sheets API. This includes: Creating comment threads and replying to comment threads using the InsertCommentRequest and AddCommentReplyRequest . Modifying existing comment and reply posts using UpdateCommentPostRequest .
